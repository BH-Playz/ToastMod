# ToastMod

ToastMod adds several items:

**Bread Slice**: The same as vanilla bread. 4 can be obtained from 1 vanilla bread in a stonecutter

**Toast**: Gives 1/2 more drumsticks compared to normal bread and can be obtained by cooking bread slices in a furnace.

**Burnt Toast**: It is not edible. Obtainable by putting toast in a furnace. Why would you do this.

**Raw Enderman**: Gives +1 drumstick with a 50/50 chance to give you the hunger effect and teleport you to a random place in a 16 block radius, obtainable by killing an enderman

**Cooked Enderman**: The same as raw enderman just without hunger. Obtainable by cooking raw enderman in a furnace. Gives +2 drumsticks as well.

*More items may be added soon.*

NOTE: 1.21.2 is NOT supported

## Open-source?

Currently ToastMod is not open-source. We only use GitHub as an issue tracker. This may be changed in the future.
